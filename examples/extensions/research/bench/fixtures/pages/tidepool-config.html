Overview

Tidepool configuration

Tidepool reads a single TOML file at start-up. Every key has a default, so an empty file is a valid configuration.

Retention

By default Tidepool retains messages for 72 hours before they are compacted away. Set retention_hours to change the window; a value of zero keeps messages until a consumer acknowledges them.

Partitions

New topics get 8 partitions unless partitions says otherwise. Partition counts can only grow.
