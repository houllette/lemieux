Tidepool overview

Tidepool is a small, fictional message broker used in these fixtures. It groups messages into partitions and lets consumers replay them.

Network

Tidepool listens on TCP port 7433 by default. The port can be changed with the listen key in the configuration file, but the fixture documentation everywhere assumes the default.

Clients connect with a plain-text handshake and then switch to a binary framing protocol. TLS is optional and off by default.
