Tidepool command line

The tidepool binary bundles the broker and its administration commands.

tidepool drain

Moves every unacknowledged message off a broker so it can be stopped. The tidepool drain command refuses to run unless the --confirm flag is passed, because draining a busy broker stalls its consumers.

tidepool top

Shows live throughput per topic. Press q to quit.

tidepool snapshot

Writes every partition to a directory of segment files.
