# Actual learned skill native review

This packet retains the first selected text skill from the registered v5 hosted
mechanism study: Graph development task 2, frozen arm, repetition 1. That episode
completed with 98 physical requests, 1,020,608 tokens and known usage. Its full
hosted scope was still running when this packet was created. The
[origin](origin.json) binds its plan, episode evidence and search receipt; these
hashes are provenance references, not independent proof or host authority.

[The exported native package](package/lemieux-extension.json) contains the
complete original source, including its actual creation timestamp, and a new
unconfirmed version for the receiving offline example. Every learned file byte
is preserved. Its [derivation record](package/priv/provenance.json) distinguishes
both identities and carries no approval or inherited qualification. The fixed
owner-written host is included in the package; no executable source was
generated from the learned text.

[The review](review.json) records original/adapted/restored frozen builds and a
fresh Mix consumer. A Scripted provider reads the actual skill tool output and
writes a digest witness of all 4,706 bytes. The consumer resolves the derived
identity and observes the same digest. Removing the extension restores the
baseline harness and empty witness exactly. The [retained driver](driver-v1.ex.txt)
preserves the code used for this run. The public verifier checks these artifacts
without model calls or activation.

The result is unassessed packaging evidence. It establishes neither task
improvement nor independent effectiveness, per-kind default qualification or
human release approval. The review lists the remaining CodeGate evidence.
The runnable example and its checkout dependency are documented in the
[example guide](../../../../examples/extensions/learned_skill_witness/README.md).
