# Evaluation corpora

You do not need anything in this directory to use, embed or extend Lemieux.
It holds the **synthetic** benchmark inputs that Lemieux's own evaluation
tooling and test suite run against. No file here comes from a real customer,
a private repository or a third-party project: every fixture was written by
hand or generated by a script in this tree.

| Path | What it is | Used by |
| --- | --- | --- |
| `corpus/v1` | Eleven small coding tasks with mechanical graders | `mix lemieux.eval` (nightly `eval.yml`, release candidates) |
| `fixture_sets/v1.json`, `recordings/v1.json` | Recorded model observations replayed without a provider | `mix lemieux.eval --fixture-set` |
| `baselines/` | Blessed results the evaluation gate compares against | `mix lemieux.eval --baseline` |
| `corpus/discovery-v1` | Tasks for harness-discovery campaigns ([README](corpus/discovery-v1/README.md)) | `mix lemieux.discovery`, `test/lemieux/benchmark/discovery_corpus_test.exs` |
| `corpus/investigators-v1`, `corpus/investigators-v2` | Read-only investigation questions for the delegation experiment ([v1](corpus/investigators-v1/README.md), [v2](corpus/investigators-v2/README.md)) | `examples/experiments/investigators.exs`, corpus tests |
| `corpus/experiments-v1` | Cases an experiment drives directly, with tools the recorded gate cannot equip | `examples/experiments/` |

`corpus/investigators-v2` is most of this directory by file count (about 4,400
generated files). Its `generators/build.py` (Python 3, standard library only)
rewrites `repos/`, `answers/` and `manifest.json` byte for byte.

Every task's grader is defined in its corpus's `manifest.json`: an inline
command, or a script in the case's fixture such as `check.sh`. Fixture
repositories are marked `linguist-vendored` in `.gitattributes` so they do not
count toward the repository's language statistics.

Start with [Evaluation gates](../docs/evaluations.md) for how the gate works,
and [Harness learning](../docs/harness-learning.md) for discovery campaigns.
To run the deterministic smoke subset without a provider:

```sh
mise exec -- mix lemieux.eval --suite eval/corpus/v1/manifest.json \
  --fixture-set eval/fixture_sets/v1.json --baseline eval/baselines/v1-smoke.json \
  --tag smoke --format console
```
